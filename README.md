# 📱 Tío Wicho App (Kotlin)

Aplicación móvil Android nativa en Kotlin para el sistema de fidelización "Tío Wicho Puntos". Escanea QR, acumula puntos.

## 🎯 Funcionalidad

- Escaneo QR para identificar clientes
- Registro de compras y acumulación de puntos
- Canje de recompensas
- Historial de transacciones

## 🛠️ Stack

- **Lenguaje:** Kotlin
- **UI:** Jetpack Compose
- **Build:** Gradle + Kotlin DSL

## 🚀 Quick Start

```bash
git clone https://github.com/FrankAboytes/TioWichoAppKotlin.git
# Abrir en Android Studio
# Build > Run
```
